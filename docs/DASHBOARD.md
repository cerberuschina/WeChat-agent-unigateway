# 控制台（可视化界面）

零依赖的本机网页：网关自己用标准库 HTTP 服务把页面发出来，浏览器打开就能看。
默认地址 **http://127.0.0.1:18600/**，默认**只允许本机**访问（跟批准接口同一道门）。

```jsonc
"dashboard": {
  "enabled": true,      // 不想开就 false
  "host": "127.0.0.1",  // 别随手改成 0.0.0.0
  "port": 18600
}
```

## 页面上有什么

| 区域 | 内容 |
|---|---|
| 顶部状态 | 真微信号、虚拟服务地址、最后刷新时间；绿色圆点 = 正常 |
| 概览卡片 | 已接入 agent、当前策略（密钥/白名单/管理网段）、每轮消息额度、后端类型 |
| **待批准的接入** | 每个待批准请求的来源 IP、qrcode、请求时间，以及**批准 / 拒绝**按钮（批准时可起名） |
| Agent | 名字、类型（virtual/a2a/http/exec）、是否已接入、虚拟号、队列长度、最后活动 |
| 每轮消息额度 | 按联系人显示已用/剩余（微信：用户回复前最多 10 条） |
| 最近消息 | 微信 → agent、agent → 微信 的最近 60 条（时间/方向/agent/内容） |
| 日志 | 网关日志最近 200 行（带时间与级别） |

页面每 2 秒自动刷新；右上角「立即刷新」手动拉一次。

## 它为什么只做两件事能写

批准/拒绝是**写操作**，其余全是只读。改配置仍然要你编辑 `gateway.json` —— 一个会偷偷重写配置文件的界面
比没有界面更危险（你不知道它改了哪一行）。

## 谁可以打开

和批准接口共用 `virtual.admin_cidrs`（默认 `127.0.0.1/32`, `::1/128`）：不是管理网段就
**403 + hint**，而且控制台自己的失败也会记日志。想让另一台机器看控制台，就把它加进
`admin_cidrs` —— 但那台机器同时也能批准接入，请想清楚再放。

## 从远端看（推荐姿势）

不要为了看控制台把 18600 暴露出去，用 SSH 端口转发：

```bash
ssh -N -L 18600:127.0.0.1:18600 user@网关机器
# 然后在你自己这台机器打开 http://127.0.0.1:18600/
```

## 不做什么

- 不提供"在线编辑配置 / 重启网关"（要改就改文件、重启进程）。
- 不画图表、不做历史归档（日志与消息都是内存里的环形缓冲，重启即空）。
- 不代你收发微信消息（那是 agent 的活；这里只看不碰）。
